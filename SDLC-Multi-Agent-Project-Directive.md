# Comprehensive SDLC Project Directive: SANYALnet Labs

## 1. Executive Directive & Mission
**From:** Office of the Chief Executive Officer (SANYALnet Labs)  
**To:** Cross-Functional Engineering Taskforce (`ceo`, `cto`, `cpo`, `programmer`, `reviewer`, `tester`)  
**Objective:** Conduct an exhaustive forensic audit of existing repository documentation and code artifacts, establish a precise project status, synthesize complete functional requirements, and execute end-to-end development to deliver a fully functional, production-ready application.

---

## 2. Phase-by-Phase Agent Workflow

### Phase 1: Inception & Status Audit (CEO & CPO)
*   **Agent Roles:** `ceo`, `cpo`
*   **Tasks:**
    1. Scan the workspace for legacy documents, specifications, issue trackers, and code skeletons.
    2. Synthesize a comprehensive **Project Status Report** outlining completed modules, architectural debt, and missing features.
    3. Define the final **Product Requirement Document (PRD)** specifying user journeys, layout structures, and acceptance thresholds.

### Phase 2: Architectural Blueprinting & Tech Stack Validation (CTO)
*   **Agent Roles:** `cto`
*   **Tasks:**
    1. Review the tech stack, framework versions, and dependency trees for long-term stability and security.
    2. Establish system design patterns, data flow diagrams, and API boundaries.
    3. Issue a formal architectural sign-off authorizing downstream implementation.

### Phase 3: Incremental Development & Coding (Programmer)
*   **Agent Roles:** `programmer`
*   **Tasks:**
    1. Bootstrap or refactor the source code repository adhering strictly to the CTO's architectural blueprint and the CPO's PRD.
    2. Implement missing core features, routing logic, and state management systems incrementally.
    3. Maintain clean version-control practices and ensure build pipelines compile successfully.

### Phase 4: Static Analysis & Code Review (Reviewer)
*   **Agent Roles:** `reviewer`
*   **Tasks:**
    1. Perform deep static analysis and diff audits on all implemented source code.
    2. Flag logical anomalies, race conditions, type mismatches, and structural anti-patterns.
    3. Enforce an iterative feedback loop with the `programmer` until zero critical defects remain.

### Phase 5: Dynamic Testing & Quality Assurance (Tester)
*   **Agent Roles:** `tester`
*   **Tasks:**
    1. Design and execute comprehensive test suites (unit, integration, and black-box UI testing).
    2. Stress-test edge cases, boundary parameters, and exception handling.
    3. Issue a formal QA Certificate of Compliance verifying that the application is 100% operational and defect-free.

---

## 3. Execution Command
Execute the lifecycle pipeline sequentially across your designated sub-agent modules. Begin Phase 1 immediately.
